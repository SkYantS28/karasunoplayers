## 📖 Sobre o projeto

Este projeto foi desenvolvido como uma **atividade avaliativa da graduação em Engenharia de Software da Universidade de Vassouras**.

Ele representa uma das minhas primeiras experiências práticas com **desenvolvimento de interfaces Web**, colocando em prática conceitos estudados durante a graduação.

O projeto foi construído utilizando principalmente **HTML5 e CSS3**, com foco na estruturação da página, organização dos elementos, estilização, interação visual e adaptação para diferentes tamanhos de tela.

> 🎓 **Este projeto marca uma das primeiras etapas da minha trajetória acadêmica no desenvolvimento de software.**

---

## 🎨 Interface

A interface utiliza uma identidade visual baseada em **preto, branco e tons de laranja**, com diferentes elementos visuais para organizar e apresentar o conteúdo.

Foram trabalhados efeitos de interação, imagens, menus, galerias e diferentes componentes de interface.

---

## ✨ Recursos desenvolvidos

### 🧭 Navegação

* Menu lateral;
* Links de navegação;
* Área de perfil;
* Botões e elementos interativos.

### 🖼️ Elementos visuais

* Galeria de imagens;
* Imagens de personagens;
* Slideshow;
* Efeitos de `hover`;
* Efeitos de destaque;
* Janelas de conteúdo.

### 📚 Organização do conteúdo

* Seções organizadas;
* Acordeões para exibição de informações;
* Colunas de conteúdo;
* Rodapé da página.

### 📱 Responsividade

O projeto utiliza **Media Queries (`@media`)** para adaptar a interface a diferentes tamanhos de tela.

Foram consideradas diferentes dimensões para:

* 📱 Dispositivos móveis;
* 📲 Tablets;
* 💻 Desktops;
* 🖥️ Monitores maiores.

## 🎯 Objetivo acadêmico

O principal objetivo deste projeto foi **transformar os conceitos estudados em sala de aula em uma aplicação Web prática**, permitindo experimentar a construção de uma interface desde sua estrutura até sua apresentação visual.

Além da parte técnica, o projeto contribuiu para o desenvolvimento da minha compreensão sobre:

> **estrutura → layout → estilização → interação → responsividade**
